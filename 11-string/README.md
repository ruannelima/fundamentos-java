# Strings 🔤

## 🎯 Objetivo

Praticar a utilização de `String` em Java e conhecer alguns métodos para manipular e obter informações sobre textos.

## 📚 Conceitos praticados

- `String`
- `Scanner`
- `nextLine()`
- `length()`
- `toUpperCase()`
- `toLowerCase()`
- Atribuição de valores
- Concatenação de Strings
- `System.out.println()`

## 💻 Funcionamento

O programa solicita que o usuário digite seu nome.

Depois, utiliza métodos de `String` para:

- Mostrar o nome digitado;
- Contar a quantidade de caracteres;
- Mostrar o nome em letras maiúsculas;
- Mostrar o nome em letras minúsculas.

## 🧪 Exemplo de execução

```text
Digite seu nome:
Ruanne

Olá, Ruanne!
Seu nome possui 6 caracteres.
Nome em maiusculo: RUANNE.
Nome em minusculo: ruanne.
