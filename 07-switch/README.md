# Switch 🔀

Exercício desenvolvido durante meus estudos de Java na graduação em Análise e Desenvolvimento de Sistemas.

## 🎯 Objetivo

Praticar a utilização da estrutura `switch` em Java para executar diferentes ações de acordo com o valor de uma variável.

## 📚 Conceitos praticados

* Declaração de variáveis
* Atribuição de valores
* Tipo de dado `int`
* Estrutura de seleção `switch`
* Estrutura `case`
* Estrutura `default`
* Uso do `break`
* `System.out.println()`

## 💻 Funcionamento

O programa utiliza uma variável `opcao` para selecionar uma ação por meio da estrutura `switch`.

As opções disponíveis são:

* `1` → Cadastrar
* `2` → Consultar
* `3` → Sair
* Outros valores → Opção inválida

### Exemplo de saída

```text
Cadastrar
```
