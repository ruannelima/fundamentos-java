# Arrays 📦

## 🎯 Objetivo

Praticar a criação e utilização de **arrays em Java**, trabalhando com armazenamento de vários valores, estruturas de repetição, entrada de dados e operações sobre os elementos.

## 📚 Conceitos praticados

* Arrays (`int[]`)
* Índices de arrays
* Índice iniciando em `0`
* `for`
* `Scanner`
* Entrada de dados com `nextInt()`
* Acesso aos elementos com `numeros[i]`
* Acumulador
* Soma dos elementos
* Estruturas condicionais (`if`)
* Operador de comparação `==`
* Operador `>`
* Identificação do maior valor

## 💻 Funcionamento

O programa:

1. Cria um array para armazenar **5 números**.
2. Solicita os números ao usuário através do `Scanner`.
3. Armazena cada número em uma posição do array.
4. Calcula a soma dos valores.
5. Identifica o maior número digitado.
6. Exibe todos os números armazenados.
7. Exibe a soma dos números.
8. Exibe o maior número.

Um ponto importante é que o primeiro número digitado é utilizado como ponto de partida para encontrar o maior valor. Isso permite que o programa também funcione quando todos os números forem negativos.

## 🧠 O que aprendi

Aprendi que os arrays possuem **índices**, começando sempre pela posição `0`.

Também pratiquei o uso do `for` para percorrer todas as posições do array e entendi a diferença entre:

```java
i = 0
```

que atribui um valor,

e:

```java
i == 0
```

que compara se `i` é igual a `0`.

Além disso, pratiquei o uso de uma variável acumuladora para realizar a soma dos valores e uma comparação para encontrar o maior número.
