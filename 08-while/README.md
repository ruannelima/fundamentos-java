# While 🔁

Exercício desenvolvido durante meus estudos de Java na graduação em Análise e Desenvolvimento de Sistemas.

## 🎯 Objetivo

Praticar a utilização da estrutura de repetição `while` em Java, utilizando uma variável de controle para repetir um bloco de código enquanto uma condição for verdadeira.

## 📚 Conceitos praticados

* Declaração de variáveis
* Tipo de dado `int`
* Estrutura de repetição `while`
* Variável de controle
* Condição de repetição
* Operador relacional `<=`
* Incremento da variável
* `System.out.println()`

## 💻 Funcionamento

O programa utiliza uma variável `numero` iniciando em `2` e imprime os números pares de `2` até `10`.

A cada repetição, o valor da variável é aumentado em `2`:

```java
numero = numero + 2;
```

A repetição continua enquanto `numero` for menor ou igual a `10`.

### Exemplo de saída

```text
2
4
6
8
10
```
