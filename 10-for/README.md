# For 🔁

Exercício desenvolvido durante meus estudos de Java na graduação em Análise e Desenvolvimento de Sistemas.

## 🎯 Objetivo

Praticar a utilização da estrutura de repetição `for` em Java, utilizando uma variável de controle para executar uma sequência de operações.

## 📚 Conceitos praticados

* Declaração de variáveis
* Tipo de dado `int`
* Estrutura de repetição `for`
* Variável de controle
* Inicialização
* Condição de repetição
* Incremento
* Operação de multiplicação
* Concatenação de Strings
* `System.out.println()`

## 💻 Funcionamento

O programa utiliza a variável `numero` com o valor `5` e um `for` para gerar sua tabuada de `1` até `10`.

A variável `i` funciona como contador e é incrementada em `1` a cada repetição:

```java
for (int i = 1; i <= 10; i++)
```

A cada repetição, o programa calcula:

```java
numero * i
```

e apresenta a operação completa no console.

### Exemplo de saída

```text
Tabuada do 5:
------------------
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
5 x 6 = 30
5 x 7 = 35
5 x 8 = 40
5 x 9 = 45
5 x 10 = 50
```

## 🧠 Aprendizado

Neste exercício, a estrutura `for` foi utilizada para controlar uma sequência de repetições, permitindo combinar uma variável de controle com uma operação matemática e apresentar os resultados utilizando concatenação.
