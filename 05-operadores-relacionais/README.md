# Operadores relacionais ⚖️

Exercício desenvolvido durante meus estudos de Java na graduação em Análise e Desenvolvimento de Sistemas.

## 🎯 Objetivo

Praticar a utilização de operadores relacionais em Java e o armazenamento dos resultados em variáveis.

## 📚 Conceitos praticados

* Declaração de variáveis
* Atribuição de valores
* Tipo de dado `boolean`
* Operador maior que `>`
* Operador menor que `<`
* Operador maior ou igual `>=`
* Operador menor ou igual `<=`
* Operador de igualdade `==`
* Operador de diferença `!=`
* Concatenação
* `System.out.println()`

## 💻 Funcionamento

O programa utiliza dois números inteiros e realiza operações relacionais entre eles.

### Exemplo de saída

```text
Maior: true
Menor: false
Maior ou igual: true
Menor ou igual: false
Igual: false
Diferente: true
```
