# Estruturas condicionais 🔀

Exercício desenvolvido durante meus estudos de Java na graduação em Análise e Desenvolvimento de Sistemas.

## 🎯 Objetivo

Praticar a utilização de estruturas condicionais em Java para tomar decisões com base em diferentes condições.

## 📚 Conceitos praticados

* Declaração de variáveis
* Tipo de dado `double`
* Operadores relacionais
* Estrutura condicional `if`
* Estrutura condicional `else if`
* Estrutura condicional `else`
* Condições booleanas
* `System.out.println()`

## 💻 Funcionamento

O programa simula um sistema de avaliação de notas utilizando as estruturas condicionais `if`, `else if` e `else`.

A partir da nota informada, o programa verifica:

* Nota maior ou igual a 7: **Aprovado**
* Nota maior ou igual a 5: **Recuperação**
* Nota abaixo de 5: **Reprovado**

### Exemplo de saída

```text
Reprovado
```
