# Variáveis e tipos de dados ☕

Segundo exercício desenvolvido durante meus estudos de Java na graduação em Análise e Desenvolvimento de Sistemas.

## 🎯 Objetivo

Praticar a declaração de variáveis, atribuição de valores e utilização de diferentes tipos de dados.

## 📚 Conceitos praticados

- Declaração de variáveis
- Atribuição de valores
- `String`
- `int`
- Concatenação
- `System.out.println()`

## 💻 Funcionamento

O programa armazena informações como nome, idade, curso e cidade em variáveis e posteriormente exibe essas informações no console.

### Exemplo de saída

```text
Olá, meu nome é Ruanne
Tenho 25 anos.
Estou cursando Análise e Desenvolvimento de Sistemas
Moro no Rio de Janeiro
